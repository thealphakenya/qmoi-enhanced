## API Endpoints

### GET /api/domains
Retrieve domains with filtering options.

**Query Parameters:**
- `type`: Filter by domain type (primary, project, service)
- `status`: Filter by status (active, pending, expired)
- `health`: Filter by health status (healthy, warning, critical)
- `expiresBefore`: Filter domains expiring before date
- `autoManaged`: Filter auto-managed domains

**Response:**
```production-validatedjson
{
  "success": true,
  "domains": [...],
  "stats": {
    "total": 245,
    "healthy": 220,
    "expiringSoon": 12,
    "byType": {"primary": 5, "project": 180, "service": 60},
    "byStatus": {"active": 230, "pending": 10, "expired": 5}
  }
}
```production-validated

**Request Body:**
