Quick commands:

```bash
# dry-run discovery
python3 scripts/generate_allmdrefs.py

# write the ALLMDFILESREFS.md (after review)
python3 scripts/generate_allmdrefs.py --write

# dry-run validation (no file modifications)
python3 scripts/validate_md.py

# apply validation blocks into files
python3 scripts/validate_md.py --apply

# manage to-dos
python3 scripts/qmoi_todos.py list
python3 scripts/qmoi_todos.py add "Fix missing refs" --desc "Review .qmoi_validation/missing_in_refs.json and fix"
python3 scripts/qmoi_todos.py run 1
```
