To deploy QVillage Enhanced:
1. Install dependencies: `pip install -r requirements.txt`
2. Run application: `python qvillage/app.py`
3. Access UI: `http://localhost:7860` (token: master_access_granted)
4. Access API: `http://localhost:8000` with docs at `/docs`
