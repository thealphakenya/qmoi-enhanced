## Installation Guide

### Windows

`Download .exe → Double-click → Follow installer`

### macOS

`Download .dmg → Open → Drag to Applications`

### Linux DEB

`sudo dpkg -i app.deb`

### Android

`Download .apk → Enable Unknown Sources → Install`

### iOS

`Download from App Store or via device management`
