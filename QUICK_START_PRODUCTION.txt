Authentication:
  POST /api/auth/signup          - Create account
  POST /api/auth/signin          - Login (password or biometric)
  POST /api/auth/profile         - Get user profile
  POST /api/auth/settings        - Update settings
  POST /api/auth/biometric/capture - Enroll biometric

QMOI Integration:
  POST /api/qmoi/chat            - Chat with AI
  GET  /api/qmoi/context         - Get user context
  POST /api/qmoi/memory/log      - Log event

Communities:
  GET  /api/qvillage/communities         - List communities
  POST /api/qvillage/communities         - Create community
  POST /api/qvillage/communities/join    - Join community
  POST /api/qvillage/communities/leave   - Leave community
