# QMOIAIUI.md - QMOIAI UI and Experience Specification

## Overview
This document captures the UI expectations for the QMOIAI interface, including avatar, workflow, and operational controls.

## UI Standards
- responsive interface
- theme-aware presentation
- task and validation visibility
- GitHub proof status display
- branch and sync visibility
- live readiness and health indicators

## Alignment Rules
The QMOIAI visual layer must remain consistent with the repo’s core resilience and sync capabilities.
