# lion-sdk

Description
- SDK bundles for external languages and runtimes: Node.js, Go, and Java connectors to LION's plugin API.

Key features
- Client libraries with typed interfaces and examples
- Language-specific examples for publishing handlers and interacting with the queue

Release & packaging
- Published to language registries (npm, Maven, Go modules) and GitHub releases.
