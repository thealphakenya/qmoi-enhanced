# QCITYUI.md - QCITY UI and Experience Specification

## Overview
This document defines the UI expectations for the QCITY workspace and file-management experience.

## UI Standards
- file navigation clarity
- structure-aware operations
- real-time state visibility
- resilient handling of missing or partial repo state
- clear integration with QMOI automation

## Alignment Rules
QCITY UI must remain consistent with the repository’s master operational and docs governance model.
