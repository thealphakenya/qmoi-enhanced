# SISTER.md - Sister Role and Access Guide

## Overview
The `sister` role is designed for collaborative access, personal content management, and advanced goal tracking within the QMOI ecosystem.
This role has expanded visibility over QMOI Space and memory-driven features while remaining restricted from full system administration.

## Sister Role Capabilities
- Access personal and team goals
- Use QMOI Space collaboration tools
- View community datasets and shared AI models
- Access memory-aware content and assistant workflows
- Manage wallet and personal preferences

## Permissions
Sister permissions configured in `app/hooks/useAuth.ts`:
- `general_chat`
- `personal_content`
- `goals_management`
- `wallet_view`
- `qmoi_space_access`
- `memory_access`

## UI Access
- Use QCity dashboard for collaboration metrics
- Open QMOI Space marketplace for model and dataset interaction
- Access QVillage datasets and marketplace previews
- Install QMOI AI or QMOI Space PWA for offline and quick access

## Recommended Workflows
### Creative Collaboration
1. Open `/qcity` for dashboards and shared insights
2. Open `/qmoi-space.html` for marketplace access
3. Use QVillage and dataset sharing tools for community collaboration

### Personal Project Management
1. Connect with QMOI AI assistant through `/qmoi-ai.html`
2. Use memory-enabled chat to preserve context
3. Sync personal preferences to PWA shells and workspace
