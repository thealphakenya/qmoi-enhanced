## 📚 API Documentation

### **Q-Converse API**

#### Start Voice Recognition

```javascript
POST /api/qmoi/converse/start
{
  "language": "en|sw",
  "continuous": true,
  "interruption": true
}
```

#### Stop Voice Recognition

```javascript
POST / api / qmoi / converse / stop;
```

#### Get Voice Status

```javascript
GET / api / qmoi / converse / status;
```
