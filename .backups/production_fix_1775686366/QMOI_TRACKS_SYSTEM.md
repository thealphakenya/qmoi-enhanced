# QMOI Tracks System

## Overview

The QMOI Tracks System provides comprehensive monitoring and tracking for all auto-projects, domains, links, emails, sites, and platform features. It enables master users to monitor system health, progress, and performance in realtime.

## Features

### Track Types
- **Auto Projects**: Generated projects with full lifecycle tracking
- **Domains**: Domain registration, health monitoring, and management
- **Domain Health**: Automated domain health checks with DNS validation and fallback monitoring
- **Links**: Link shortening, analytics, and performance tracking
- **Link Validation**: Automated link validation with token normalization and auto-fix capabilities
- **Emails**: Email infrastructure monitoring and delivery tracking
- **Sites**: Website deployment and uptime monitoring
- **Platforms**: Cross-platform feature deployment tracking
- **Payments**: Payment processing and transaction tracking

### Track Lifecycle
1. **Pending**: Track created, waiting to start
2. **Active**: Track currently executing
3. **Paused**: Track temporarily stopped
4. **Completed**: Track finished successfully
5. **Failed**: Track encountered an error

### Priority Levels
- **Critical**: System-critical operations
- **High**: Important business operations
- **Medium**: Standard operations
- **Low**: Background maintenance tasks

## API Endpoints

### GET /api/qmoi-tracks
Retrieve tracks with optional filtering.

**Query Parameters:**
- `type`: Filter by track type (auto-project, domain, domain-health, link, link-validation, email, site, platform, payment)
- `status`: Filter by status (pending, active, paused, completed, failed)
- `priority`: Filter by priority (critical, high, medium, low)
- `createdAfter`: Filter tracks created after date
- `createdBefore`: Filter tracks created before date
- `tags`: Filter by metadata tags (comma-separated)

**Response:**
```json
{
  "success": true,
  "tracks": [...],
  "stats": {
    "total": 150,
    "byType": {"auto-project": 45, "domain": 32, ...},
    "byStatus": {"active": 23, "completed": 89, ...},
    "byPriority": {"high": 15, "medium": 78, ...},
    "averageProgress": 67,
    "activeTracks": 23,
    "completedTracks": 89,
    "failedTracks": 3
  }
}
```

### POST /api/qmoi-tracks
Create a new track.

**Request Body:**
```json
{
  "name": "Auto-Project: E-commerce Platform",
  "type": "auto-project",
  "metadata": {
    "projectName": "E-commerce Platform",
    "projectType": "web-app",
```
