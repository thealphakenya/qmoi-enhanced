TASK: Make the GitHub-hosted Ollama Autonomous Agent Truly Autonomous Until Completion

You are modifying the repository's GitHub Actions implementation of the Ollama Autonomous Agent.

Your objective is NOT merely to make the workflow green.

Your objective is to guarantee that, whenever a trusted GitHub-hosted autonomous-agent run starts, it continues through every required stage and does not pause, silently skip, falsely succeed, or declare completion until the complete autonomous-agent success contract has actually been satisfied.

The implementation must remain bounded, safe, auditable, and GitHub-hosted.

---

1. PRIMARY REQUIREMENT

Treat the autonomous-agent workflow as a state machine with an explicit completion contract.

A run may terminate as successful ONLY when ALL required states have been objectively verified.

At minimum:

1. GitHub-hosted runner initialized.
2. Correct repository and target branch checked out.
3. Required source files/workflows/scripts available.
4. Python runtime initialized.
5. Ollama installed/started successfully.
6. Ollama health endpoint responds successfully.
7. Required model is available.
8. A real Ollama inference has been executed successfully.
9. The autonomous coding loop has actually started.
10. The agent has performed its required work rather than merely initializing.
11. The bounded iteration/circuit-breaker policy has been respected.
12. Repository changes, if required, have actually been applied.
13. Required tests/validation have actually run.
14. Validation has passed.
15. Repository state has been checked after agent execution.
16. Resume/checkpoint state has been persisted.
17. Required telemetry/evidence has been persisted.
18. The final success contract has been generated.
19. The success contract independently verifies every required condition.
20. The final health gate refuses success if any required condition is false, missing, skipped, or unknown.
21. The workflow artifact contains sufficient evidence to independently reconstruct what happened.
22. The final workflow conclusion is SUCCESS only after all of the above are true.

Do NOT use a green preceding job, successful checkout, successful Ollama installation, or successful wrapper script as proof of autonomous completion.

6. NO UNBOUNDED INFINITE LOOP

"Do not pause until complete" does NOT mean create an infinite GitHub Actions loop.

Implement a bounded circuit breaker.

The agent should continue through retries/iterations until:

SUCCESS

All required completion conditions are true.

RECOVERABLE FAILURE

A bounded retry is available.

Retry and continue.

TERMINAL FAILURE

No safe retry remains or an unrecoverable condition exists.

Fail explicitly with diagnostic evidence.

The agent must NEVER remain indefinitely:

queued
in_progress
waiting
sleeping
retrying

without making progress or reaching a terminal state.

Every retry must have:

- attempt number
- reason
- timestamp
- action
- result
- next action

7. "PAUSE" MUST HAVE A STRICT DEFINITION

The autonomous agent must not voluntarily pause simply because:

- one iteration completed;
- the repository appears unchanged;
- an upstream workflow was successful;
- the workflow was triggered by "workflow_run";
- a checkpoint exists;
- Ollama is healthy;
- one test passed;
- the model returned an answer;
- an intermediate step succeeded.

A pause/wait is permitted ONLY when it is an intentional bounded wait for an external GitHub-hosted condition such as:

- Ollama startup/readiness;
- GitHub workflow dependency completion;
- retry backoff;
- GitHub API propagation.

Every wait must have:

- explicit timeout;
- bounded polling;
- observable progress;
- terminal failure if timeout expires.
