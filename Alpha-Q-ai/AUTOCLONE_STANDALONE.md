# AUTOCLONE_STANDALONE.md

The standalone autoclone layer keeps QMOI operational across GitHub, Netlify, Vercel, Gitpod, Hugging Face, and all cloned platforms. It automates repo sync, environment setup, deployment hooks, and platform parity refreshes.

## Active automation
- repo sync and autoclone loops remain active in the live runtime.
- platform-specific config files such as netlify.toml are kept synchronized.
- the autonomous agent validates all clone/autoclone states before final promotion.
