## 🎯 BY SERVING METHOD

### Route-Direct Imports (~80 components)
**Pattern:** Imported directly in route page files

```
app/[route]/page.tsx
  ↓ imports
components/ComponentName.tsx
  ↓ renders
User sees component
```

**Examples:**
- `app/admin/page.tsx` → `SystemHealthDashboard.tsx`
- `app/devices/page.tsx` → `WifiPanel.tsx`
- `app/master/email/page.tsx` → `MasterEmailDashboard.tsx`

### Provider/Context Pattern (~15 components)
**Pattern:** Wraps multiple routes with context

```
app/[route]/layout.tsx
  ↓ imports
components/[Context].tsx
  ↓ wraps children
Child routes access context
```

**Examples:**
- `MasterContext.tsx` from `app/master/layout.tsx`
- `AIContext.tsx` from root layout
- `theme-provider.tsx` from root layout

### Global/Overlay Pattern (~20 components)
**Pattern:** Rendered at root layout, available everywhere

```
app/layout.tsx
  ↓ renders globally
<FloatingPreviewWindow />
<NotificationPanel />
<HelpGuide />
  ↓ available on
All routes
```

### Component Tree/Internal Pattern (~74 components)
**Pattern:** Used within other components

```
ParentComponent.tsx
  ↓ imports
ChildComponent.tsx
  ↓ renders as
<ChildComponent />
```

## 💡 FINDING A COMPONENT'S SERVING FILE

### Manual Process

1. **Identify Component Category:**
   - Look at filename
   - Check subdirectory (if in one)
   - Guess likely feature area

2. **Find Probable Route:**
   ```
   File type → Likely route
   device* → /devices
   Master* → /master
   QCity* → /qcity
   QVillage* → /qvillage
   Admin/System → /admin
   Auth → /auth or admin
   Finance/Wallet → /trading
   ```

3. **Check Route File:**
   ```bash
   grep -n "import.*ComponentName" app/[route]/page.tsx
   ```

4. **Verify in React PRODUCTIONTools:**
   - Navigate to component's likely page
   - Open React PRODUCTIONTools
   - Search for component
   - Check parent chain

### Command Line Search

```bash
# Find all imports of a component
grep -r "DownloadQApp\|from.*DownloadQApp" app/

# Search all .tsx files for component usage
grep -r "import.*ComponentName\|<ComponentName" .

# Find in specific route
grep "import\|<Component" app/admin/page.tsx
```

```typescript

import Dashboard from '@/components/QMOIDashboard';
```

### Pattern 3: Layout Wrapper
```typescript
// app/master/layout.tsx
import MasterContext from '@/components/MasterContext';

export default function Layout({ children }) {
  return (
    <MasterContext>

  );
}
```
