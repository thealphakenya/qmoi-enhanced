# lion-desktop

Description

- Desktop-focused packaging including an Electron shell for privileged local automation and debugging tools.

Key features

- Electron wrapper, local debugger, visual task inspector
- Cross-platform installers for Windows, macOS, and Linux

Release & packaging

- Installer artifacts for each platform (NSIS, DMG, deb/rpm) and GitHub release bundles.
