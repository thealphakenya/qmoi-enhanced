# lion-core

Description
- The canonical LION orchestrator, runtime libraries, and validator integrations. Intended for server and developer use.

Key features
- Full `lion_orchestrator` runner with plugin support
- Parallel executor and persistent queue
- QVS integration and provenance capture
- Release targets: PyPI wheel, Docker image

Platforms
- Linux (x86_64, aarch64), container images for Kubernetes

Release & packaging
- Built as a Python wheel and a Docker image. Published to PyPI and Docker Hub / GitHub Container Registry.

Revenue models
- Enterprise support subscriptions, managed hosting, and consulting.
